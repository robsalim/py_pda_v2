# PDA Next-Gen

Настольное приложение для сбора, регистрации и визуализации данных с промышленных
контроллеров (Siemens S7, Modbus TCP) на PyQt6. Ведёт собственную историю сигналов,
показывает живые графики в GUI и отдаёт их же через встроенный веб-вьювер.

## Возможности

- **Драйверы**: Siemens S7 (snap7), Siemens S7-200 SMART (snap7, V-память:
  VW100 / VD20 / V100.3), Modbus TCP-клиент и Modbus TCP-сервер
- **Вкладка I/O Configuration** — дерево модулей/групп, таблица переменных с живыми
  значениями, импорт/экспорт CSV и JSON, копирование переменных со сдвигом адреса
- **Вкладка Charts** — живые/архивные графики с курсорами X1/X2, ΔT и значениями
  по Y в легенде; несколько окон на вкладке; дерево сигналов (drag & drop)
- **Вкладка Bits** — распаковка 8-16 битных регистров (BYTE/INT16/UINT16) во
  временную диаграмму; дерево сигналов с фильтром по этим типам
- **Светлая и тёмная темы** с пастельной палитрой кнопок (выбор запоминается)
- **Историк** — асинхронная запись в БД пачками (COV + интервал + deadband),
  ротация по retention
- **Веб-вьювер** — Charts и Bits в браузере (`http://localhost:8082`), с тем же
  деревом сигналов и историческим бэкендом
- **Базы данных**: SQLite (из коробки), PostgreSQL (+TimescaleDB опционально),
  MySQL/MariaDB — переключение из GUI

## Требования

- Windows, Python 3.10+
- python-snap7 требует системную DLL `snap7` (для драйвера Siemens)

## Установка

1. Клонируйте репозиторий:
   ```bat
   git clone https://github.com/robsalim/py_pda_v2.git
   cd py_pda_v2
   ```
2. Запустите **`setup.bat`** — он создаст виртуальное окружение `.venv`
   и поставит зависимости из `requirements.txt`.

## Запуск

Дважды щёлкните **`run.bat`** — приложение стартует без окна консоли
(`pythonw main.py` из `.venv`).

Или вручную:
```bat
.venv\Scripts\activate
python main.py
```

Веб-вьювер поднимается автоматически вместе с приложением:
`http://localhost:8082` (хост/порт — `config.py`, `WEB_HOST`/`WEB_PORT`).

## Настройка базы данных

По умолчанию используется SQLite (`db_config.json`, файл `data/pda_local.db`) —
база создаётся автоматически, ничего настраивать не нужно.

PostgreSQL / MySQL подключаются во вкладке **Database & Storage**: хост, порт,
пользователь, пароль и имя базы сохраняются в `db_config.json` (файл не попадает
в git — держите его в секрете).

## Конфигурация (`config.py`)

| Параметр | Назначение |
|---|---|
| `DB_CONFIG` | дефолтные параметры подключения к БД |
| `WEB_HOST`, `WEB_PORT` | адрес встроенного веб-сервера |
| `DEFAULT_MODBUS_SERVER_PORT` | порт Modbus TCP-сервера (502 требует прав администратора) |
| `JOURNAL_CONFIG` | частота записи в историю, размер пачки, срок хранения |

## Структура проекта

```
main.py             точка входа (GUI + веб-сервер + драйверы)
config.py           дефолтные настройки
core/               оперативный реестр тегов (TagRegistry/TagPoint) и журнал (Historian)
database/           слой БД (SQLite/PostgreSQL/MySQL), фоновый писатель (Collector)
drivers/            драйверы Modbus и S7, менеджер драйверов
models/             dataclass-модели (Connection, Tag, DataPoint)
ui/                 вкладки PyQt6 (I/O, Charts, Bits, настройки БД)
web/                статическая страница веб-вьювера (uPlot)
web_server.py       FastAPI-бэкенд веб-вьювера
tests/              смоук-тесты конвейера и UI
```
